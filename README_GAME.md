# README for Cricket Game Prototype

This repository contains a Streamlit-based cricket game prototype.

How to run locally:
1. Install dependencies: pip install -r requirements.txt
2. Run: streamlit run app_game.py

How to deploy on Streamlit Community Cloud:
1. Go to https://share.streamlit.io and sign in.
2. Click "New app" and select this repository (movieeditz998-ship-it/cricket-xapp).
3. For branch, select feature/match-simulator.
4. For main file, set app_game.py and deploy.

Notes:
- This is a simple prototype (ball-by-ball simulator with basic commentary and options).
- For sounds, assets, realistic characters, and Android builds we need to develop a Unity project separately.
