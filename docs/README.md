# Quick Cricket Prototype

This is a very small, fast web prototype added to the repository to give a playable demo quickly.

Files are in the `docs/` folder so you can publish with GitHub Pages (serve from `docs/` in repository settings) or open `docs/index.html` locally in a browser.

How to run locally:
1. Open docs/index.html in your browser.
2. Click "Start Quick Match" and swipe/drag inside the play area to play shots.
3. Save match results to localStorage and view league standings.
