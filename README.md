# Cricket-xapp

This repository contains a Streamlit app "Cricket League Dashboard & Manager".

Branch: `main`
App (entry) filename: `app.py`

## Quick deploy to Streamlit Community Cloud
1. Go to https://share.streamlit.io and log in with your GitHub account.
2. Click "New app" → select repository `movieeditz998-ship-it/Cricket-xapp` → branch `main` → file `app.py` → Deploy.
3. Streamlit will provide a live URL (copy it). To update the README with the live URL, paste it in an issue or update the README.
